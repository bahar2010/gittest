## 📋 Installation Instructions

### 1. Upload Theme
```bash
# Option 1: WordPress Admin
1. Go to Appearance > Themes > Add New > Upload Theme
2. Upload the theme zip file
3. Activate the theme

# Option 2: FTP
1. Upload theme folder to /wp-content/themes/
2. Activate via WordPress admin
```

### 2. Initial Setup
1. **Create Pages**:
   - Home (set as homepage)
   - Portfolio (use Portfolio template)
   - About
   - Contact (use Contact template)
   - Services

2. **Set Up Navigation**:
   - Go to Appearance > Menus
   - Create primary menu
   - Add pages to menu

3. **Add Portfolio Items**:
   - Go to Portfolio > Add New
   - Add titles, descriptions, images
   - Assign categories
   - Mark as "Featured" for homepage

### Adding Portfolio Items
1. Go to **Portfolio > Add New**
2. Add title and description
3. Set featured image (400x300px recommended)
4. Assign category (Wedding, Portrait, Event, etc.)
5. Check "Featured on Homepage" if desired
6. Publish
