# Photographer Pro - WordPress Theme

A modern, responsive WordPress theme designed specifically for photographers. Features include a home page slider, portfolio/album pages, and clean, elegant design optimized for showcasing photography work.

### 🎨 Design & Layout
- **Modern, Clean Design** - Minimalist aesthetic that puts focus on your photos
- **Fully Responsive** - Looks great on all devices (desktop, tablet, mobile)
- **Fast Loading** - Optimized for performance and SEO
- **Custom Typography** - Beautiful Inter font for excellent readability

### 📸 Photography-Focused Features
- **Hero Slider** - Showcase your best work on the homepage
- **Portfolio Grid** - Beautiful gallery layout with hover effects
- **Lightbox Gallery** - Click to view images in full-screen overlay
- **Portfolio Filtering** - Filter by categories (Wedding, Portrait, Event, etc.)

### 📱 User Experience
- **Smooth Animations** - Subtle hover effects and transitions

## Installation

### Method 1: Upload via WordPress Admin
1. Download the theme files
2. Go to **Appearance > Themes** in your WordPress admin
3. Click **Add New** then **Upload Theme**
4. Choose the theme zip file and click **Install Now**
5. Activate the theme

### Method 2: FTP Upload
1. Extract the theme files
2. Upload the `photographer-pro` folder to `/wp-content/themes/`
3. Go to **Appearance > Themes** and activate **Photographer Pro**

## Setup Guide

### 1. Initial Configuration
After activating the theme:

1. **Customize Your Site**
   - Go to **Appearance > Customize**
   - Set your site title and tagline
   - Upload your logo
   - Configure colors and typography

2. **Create Pages**
   - **Home** - Set as your homepage
   - **Portfolio** - Use the Portfolio template
   - **About** - Tell your story
   - **Contact** - Use the Contact template
   - **Services** - List your photography services

3. **Set Up Navigation**
   - Go to **Appearance > Menus**
   - Create a new menu and assign it to "Primary Menu"
   - Add your pages to the menu

### 2. Portfolio Setup

#### Adding Portfolio Items
1. Go to **Portfolio > Add New**
2. Add a title and description
3. Set a featured image (recommended size: 400x300px)
4. Assign a category (Wedding, Portrait, Event, etc.)
5. Check "Featured on Homepage" if you want it on the slider
6. Publish

#### Portfolio Categories
- **Wedding Photography**
- **Portrait Sessions**
- **Event Photography**
- **Landscape Photography**
- **Family Sessions**
- **Corporate Events**

### 3. Homepage Slider
The homepage slider automatically displays:
- Featured portfolio items, OR
- Default images if no portfolio items are featured

To customize slider images:
1. Go to **Appearance > Customize > Hero Section**
2. Upload your slider images
3. Set titles and subtitles for each slide

### 4. Contact Information
Configure your contact details:
1. Go to **Appearance > Customize > Contact Information**
2. Add your email, phone, and address
3. Set up social media links

## Support

### Common Issues

**Slider not working?**
- Check if you have portfolio items marked as "Featured"
- Ensure images are properly uploaded

**Portfolio not displaying?**
- Make sure you've created portfolio items
- Check that the Portfolio page uses the Portfolio template

**Contact form not working?**
- Install a contact form plugin like Contact Form 7
- Configure email settings in WordPress

**Images not loading?**
- Check file permissions
- Ensure images are properly uploaded to media library
