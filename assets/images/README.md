## Image Specifications

### Format
- Use **JPEG** format for photographs
- Use **PNG** format for graphics with transparency
- Use **WebP** format for better performance (with JPEG fallback)

### Quality
- **Hero images**: High quality (80-90%)
- **Portfolio thumbnails**: Medium quality (70-80%)
- **Profile images**: High quality (80-90%)

### Optimization
- Compress images before uploading
- Use appropriate file sizes:
  - Hero images: 200-500KB
  - Portfolio thumbnails: 50-150KB
  - Profile images: 100-300KB

When using sample images, ensure you have proper licensing:

## Customization

Replace these images with your own photography work:
1. Upload your images to the WordPress Media Library
2. Update the theme customizer settings
3. Replace portfolio items with your actual work
4. Update the about section with your photo

## Performance Tips

1. **Optimize images** before uploading
2. **Use WebP format** when possible
3. **Implement lazy loading** for better performance
4. **Use CDN** for faster image delivery
5. **Compress images** without losing quality
